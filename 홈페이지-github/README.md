# 나의 창작 공방

그리고, 쓰고, 작곡하는 개인 홈페이지입니다.

- **이모티콘 그리기** (`emoji.html`): 펜·지우개·채우기로 그리고 PNG로 저장
- **소설 쓰기** (`novel.html`): 작품·장별로 쓰고 자동 저장, TXT로 내보내기
- **작곡하기** (`compose.html`): 칸을 눌러 멜로디·드럼을 만들고 WAV로 저장
- **이미지 갤러리** (`gallery.html`): 픽사베이 무료 이미지 검색

## 이미지 갤러리 사용하기

API 키는 저장소에 올리지 않습니다. `config.example.js`를 `config.js`로 복사하고
[픽사베이 API 키](https://pixabay.com/api/docs/)를 넣으면 갤러리가 동작합니다.
